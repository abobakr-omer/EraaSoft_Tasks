Employee Management

Spring Boot REST API Dashboard

Read Operations

Load employees from the database.

GET

Show All Employees

List every employee stored in the database.

/employee/all-employees GET

Get Employees By IDs

Load several employees from a list of IDs.

/employee/all-employees-By-Ids/{ids} GET

Search By Name

Search using Derived Query, Native SQL or JPQL.

/employee/search-by-derived/{name}

Create & Update

Add new employees or change existing ones.

POST

Add Employee

Create a single new employee record.

/employee/save-employee PUT

Update Employee

Edit a single existing employee.

/employee/update-employee POST

Save Multiple Employees

Create many employees from a JSON array.

/employee/save-employees PUT

Update Multiple Employees

Update many employees from a JSON array.

/employee/update-employees

Delete Operations

Remove employees from the database.

DELETE

Delete Employee

Remove a single employee by ID.

/employee/delete-employee/{id} DELETE

Delete Employees By IDs

Remove several employees from a list of IDs.

/employee/delete-employees-by-ids/{ids} DELETE

Delete All Employees

Remove every employee from the database.

/employee/delete-all-employees
